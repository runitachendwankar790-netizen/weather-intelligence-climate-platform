# Weather Intelligence and Climate Decision Support Platform

## MacroEdtech GenAI Research 2026 - Phase 02 part 1

AI-based Weather Prediction System for Indian Southwest Monsoon rainfall analysis and prediction.

## Project Objective

The objective is to develop an AI-powered Weather Intelligence Platform using historical Indian rainfall data, machine learning, time-series forecasting, explainable AI, FastAPI and Streamlit.

## Dataset

Dataset: India Rainfall 1901-2015

Records: 4116

Original columns: 19

Important variables include SUBDIVISION, YEAR, monthly rainfall variables, ANNUAL and seasonal rainfall variables.

## Data Processing

1. Data loading
2. Data inspection
3. Missing-value analysis
4. Missing-value treatment
5. Feature engineering
6. Exploratory data analysis
7. Train-test splitting

## Machine Learning

Models explored include Linear Regression, Ridge Regression, Lasso Regression, Decision Tree, Random Forest, Gradient Boosting, Extra Trees, XGBoost, KNN and Support Vector Regression.

## Time-Series Forecasting

ARIMA, SARIMA/SARIMAX and Exponential Smoothing were investigated.

## Deep Learning

Neural-network based approaches were investigated for rainfall prediction.

## Evaluation Metrics

MAE, MSE, RMSE and R2 were used for model evaluation.

## Explainable AI

SHAP was used to analyze feature importance and model interpretability.

## Application

FastAPI provides the prediction backend and API documentation.

Streamlit provides the Weather Intelligence dashboard.
